# 本地写作台 · tools/blog-editor

只在本机运行的图形界面，用来写、改、发博客文章和管理图片。它**不是**线上站点的一部分，`astro build` 不会打包它，Cloudflare 也不知道它存在。

```sh
npm run editor
```

会在 `http://127.0.0.1:4380/` 启动并自动打开浏览器。不想开终端的话，双击项目根目录的 **写作台.command**，它会自己起服务、自己开浏览器；关掉那个终端窗口就停了。

换端口或不自动打开：

```sh
npm run editor -- --port 4381 --no-open
```

建议同时开着 Astro 开发服务器（`astro dev --background`），右上角「在站点里看」会跳到 `http://localhost:4321/blog/<slug>/`。

## 写一条随笔：按 N

`N`（不在输入框里时）打开速记。一个屏幕上只有四件事：链接后缀、日期、栏目、标题和正文。

- **slug 自动按日期生成**：默认 `/blog/2026-09-18/`；在后缀框里随手敲几个字母就变成 `/blog/2026-09-18-late-night/`。空格和标点边打边规范成连字符，看到的就是链接里真正的样子。同一天第二条自动变 `-2`。
- **不需要摘要，也不需要封面**：`description` 在 schema 里是可选的，列表页、RSS、搜索都会优雅降级（列表只显示标题，RSS 的 description 退回标题）。
- **⌘↩ 发布**（`draft: false`），**⌘S 存草稿**（`draft: true`）。存完自动打开这篇，光标落在正文里。
- 栏目默认「思绪」，标签默认带一个「思绪」，都能改。

## 往已有文章里补一段：追加

速记面板上切到「追加到…」，或在某篇文章的工具栏点「追加一条」。选一篇，写一段，⌘↩：

```
（原正文）

## 9 月 18 日

（这次补的）
```

同时把 `updatedDate` 改成今天（`publishDate` 不动）。日期小标题和分隔线都可以关掉。

## 分屏：左写右看

工具栏第二个标签是「分屏」，或按 `⌘E` 在 只写 / 分屏 / 只看 之间轮换。右边用站点自己的 CSS 和 Markdown 管线渲染，边打字边更新。

滚动是**按段落对齐**的，不是按百分比：正文按空行切成块，第几块就滚到预览里的第几个元素。图多的文章（源码里一大段 HTML 只渲染成一张图）也能对得上。块数和预览元素数对不上时才退回按比例。

## 菜谱小卡：填表，不改 HTML

「插入… → 菜谱小卡（表单）」打开一个表单：菜名、要点、旁注、原材料、步骤、标准 / 迷你。填完插入。

**把光标放在一张已有的小卡里再按同一个按钮，会把那张卡读回表单**，改完原地替换，缩进也保留（所以放在 `recipe-card-grid` 里的卡也能改）。标题写成「改这张菜谱小卡」你就知道是在改而不是在插。

两张并排：先插「两张并排的容器」，光标会停在容器中间，再插两张迷你小卡。

## 上传时自动压图

右栏「图片」上面有一行设置：压缩开关 + 最长边（1600 / 2000 / 2400 / 3000）。手机原图在浏览器里先缩好再传：

- jpg / jpeg → jpg（质量 0.82）
- png → webp（质量 0.9，保住透明）
- gif / svg 不动
- 压不小就用原图

传完提示里会说省了多少。设置记在浏览器里，下次还在。

## 季笺也能在里面改

左栏筛选条最后一个是「季笺」，列的是 `src/content/seasons/`。点开右栏就换成季笺的表单：标题、季节、年份、摘要、日期、草稿、封面。

季笺的 `description` 在 schema 里是**必填**的（和文章不一样），检查页会盯着。首页「这一季」的三段小注取自正文里的 `## 小节`，所以正文照常在中间写。

季笺没有自己的图片目录，封面从通用封面里选；「追加一条」「图片」这些用不上的入口会自动变灰。

按 ＋ 时如果当前在「季笺」筛选下，新建的就是季笺。

## 在另一台电脑上用

写作台就是仓库里的三个文件，没有绑定任何一台机器。在另一台电脑上：

```sh
git clone https://github.com/TLSENMU/bbsens-blog.git
cd bbsens-blog
npm install
npm run editor
```

要求只有一个：那台机器上有 **Node ≥ 22.12**（`node -v` 看一下；没有就去 nodejs.org 装 LTS）。macOS 双击 `写作台.command`，Windows 双击 `写作台.bat`。

内容靠 git 同步，所以**规矩是：开写之前先「拉取」，写完「提交并推送」**。左栏最下面那条同步栏就是干这个的：

- 显示当前分支、`↓ n 待拉取`、`↑ n 待推送`、`n 处改动`；都为零时显示「和 GitHub 一致」。
- **检查** 向 GitHub 问一次有没有新的（`git fetch`），不动你的文件。
- **拉取** 是 `git pull --ff-only`：拉得动就拉，拉不动（两边改了同一个地方）就停下来告诉你，**不会在背后造合并提交，也不会覆盖你没保存的改动**。真冲突了到终端里手动解决。
- **提交并推送…** 弹一个对话框，列出将要提交的每个文件、预填一句提交信息（按改了哪几篇自动生成），确认才跑 `git add -A` → `commit` → `push`。可以取消勾选「推送到 GitHub」变成只提交到本地。

没有任何一步是自动的：服务自己不会 commit，更不会 push。仓库没有 remote 或者不是 git 仓库时，这条同步栏根本不显示。

两台同时开着写同一篇仍然会冲突——git 帮不了这个。实际用法是：这台写完推上去，再到那台拉下来接着写。

## 其它

- **⌘K** 跳到任意一篇文章（按标题、标签、slug 模糊搜），也能跑「速记 / 追加 / 新建 / 切预览」这些命令。
- **自动保存**：停下打字约 1 秒就写盘，顶栏显示「已保存 14:32」。frontmatter 有错时不会写，状态变成「未保存：有错误」。
- **磁盘守卫**：如果文件在别处（Obsidian、git、另一个编辑器）被改过，保存会被拦下，顶部出现一条提示，让你选「重新载入磁盘版本」还是「用我的版本覆盖」，不会闷头把别人的修改冲掉。
- **右栏**只放必填的：标题、栏目、日期、标签、三个开关。链接、摘要、封面、地点、语言收在「可选」里。⌘\ 可以整条收起。
- **图片**：拖进正文、粘贴、或从右栏「图片」上传，都会存到 `public/assets/posts/<slug>/`。点一张图可以插入正文、设为封面、重命名（正文里的路径跟着改）、删除（移到 `.trash`）。封面预览按 coverLayout 的比例裁切，**点一下图片就能设定 coverPosition 焦点**。
- **预览**用项目自己的 Markdown 管线（remark-math、KaTeX、figure 处理）和 `src/styles/global.css`，所以菜谱小卡、图片对看到的就是线上的样子。
- **检查**页对照 `src/content.config.ts` 的 schema 校验，并显示将要写入的 YAML。
- 工具栏「插入…」里有分隔线、图片对、竖图、宽图、菜谱小卡（走表单）、并排容器。
- 改 slug 在「可选 → 链接」里，按「改名」才生效：会一起移动图片目录、改写正文和封面里的路径（自动保存不会偷偷改名）。

## 快捷键

| 键 | 作用 |
| --- | --- |
| `N` | 速记一条随笔 |
| `⌘K` | 跳转 / 命令 |
| `⌘↩` | 发布（取消草稿并保存） |
| `⌘S` | 立即保存 |
| `⌘E` | 只写 / 分屏 / 只看 轮换 |
| `⌘\` | 收起右栏 |
| `/` | 聚焦左栏筛选框 |

## 它不做什么

- 不碰 git：保存只是写文件，什么时候 `git commit` / `push` 由你决定。
- 不碰 Cloudflare 配置、不需要登录、没有数据库。
- 不对外监听，只绑定 `127.0.0.1`。

## 文件

- `server.mjs` — Node 内建模块写的小服务，没有额外依赖。YAML 用的是 Astro 已经带进 `node_modules` 的 `js-yaml`；找不到时退回内置的极简解析。
- `index.html` — 单文件界面。
- `.trash/` — 删除的文章和图片会移到这里（已在 .gitignore 里忽略）。

改了 `src/content.config.ts` 的 schema，记得同步 `server.mjs` 里的 `validateFrontmatter` 和 `FIELD_ORDER`。
